# Third-Party Dependency: smoltcp

This directory contains the [smoltcp](https://github.com/smoltcp-rs/smoltcp) TCP/IP networking stack.

- **License**: 0BSD (see LICENSE-0BSD.txt)
- **Origin**: https://github.com/smoltcp-rs/smoltcp
- **Status**: Third-party code, NOT part of the self-developed TCB

Per the Asterinas framekernel TCB measurement methodology, third-party libraries
audited by the open-source community are excluded from the self-developed TCB ratio.
The `scripts/audit_tcb_ratio.py` script automatically excludes this directory.
