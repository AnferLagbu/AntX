| 文件 | 原 reason 声称 | 实际可行性 |

| fs/dcache.rs | "触发 unused_and_then/unnecessary_map_or 双重 lint" | ❌ 直接 .map() 无问题 |

### 根治模式分类

| 模式 | 适用场景 |
|---|---|
| `.map(f1).map(f2)` | 链式副作用转换 |
| `.map_or(default, \|x\| { 副作用; ret })` | 含副作用+返回值 |
| `.unwrap_or_else(\|\| { 副作用构造 })` | 默认值需计算 |
| `.inspect(\|x\| { 副作用 })` | 仅观察不转换（替代冗余 .map().map(identity)） |
| **提取 helper 函数** | 嵌套 match + drop 借用场景 |
| `let Some(x) = ... else { break }` | 循环中 break fallback |
