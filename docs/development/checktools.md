### 代码风格与基础检查
*   **Rustfmt**：官方标配的代码格式化工具，通过 `cargo fmt` 一键让整个项目的代码风格自动统一。
*   **Rustc**：Rust 编译器本身就带有基础检查功能，能通过 `--warn` 或 `#![deny]` 等 lint 级别，检查出未使用的变量等基础问题。

### 依赖安全与管理
*   **cargo-audit**：核心安全检查工具，扫描 `Cargo.lock` 中依赖是否有已知漏洞，并告知修复建议。
*   **cargo-deny**：更全面的依赖治理工具，能检查配置许可、检测漏洞，还能防止依赖重复。
*   **cargo-udeps**：专门找出 `Cargo.toml` 里已声明但没使用过的依赖，帮项目“减重”。
*   **cargo-crev**：基于“信任网络”的依赖审查系统，靠社区力量为依赖包的安全与质量提供担保。
*   **cargo-aprz**：通过分析依赖的各项指标（如问题数量），帮你评估使用的第三方库质量。

### 高级代码逻辑与内存安全
*   **Miri**：官方的中级中间表示（MIR）解释器，能高效检测出 `unsafe` 代码里的未定义行为。
*   **RAPx (Rust Analysis Platform with Extensions)**：来自复旦大学研究团队的静态分析平台，能在代码运行前精准检测内存泄漏等棘手问题。
*   **Prusti**：强大的静态验证器，可以给函数加“合同”（Pre/Post-condition），在编译期就证明代码不会崩溃。

### 测试质量深度分析
*   **cargo-tarpaulin** / **cargo-llvm-cov**：代码覆盖率工具，能可视化展示你的测试覆盖了代码的哪些部分。
*   **cargo-mutants**：通过给代码自动注入小 Bug 来看测试能否发现，以此评估测试用例的有效性。

### 项目健康度与度量
*   **Codelens**：高性能分析工具，从复杂度等多个维度给代码健康度打分，识别高风险文件。
*   **ruloc**：基于语法树分析的代码计数器，能精确区分生产代码与测试代码的行数。
*   **Criterion.rs**：专业的基准测试框架，提供统计分析和图表，精准测量、避免性能衰退。
*   **flamegraph**：能生成直观的火焰图，帮你轻松定位 CPU 热点和性能瓶颈。

### 一站式集成方案
如果希望统一管理，`os-checker` 这类工具可以把 Rustfmt、Clippy、Miri 等工具的运行结果汇总，生成一份综合报告。

### 选择建议
可以根据实际需求来组合使用这些工具：
*   **追求零缺陷与高性能**：可以考虑结合 **Miri** 和 **RAPx** 进行深度内存安全检查，并用 **Criterion.rs** 做基准测试。
*   **提升测试质量**：在已有代码覆盖率的基础上，引入 **cargo-mutants** 来检验测试用例的有效性。
*   **维护大型项目**：建议使用 **Codelens** 定期评估模块的健康度，辅助技术决策。
